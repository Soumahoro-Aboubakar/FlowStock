# Flowstock — Frontend

Interface React construite avec Vite et Tailwind CSS v4. La police Inter est servie localement via Fontsource.

Depuis la racine du projet :

```sh
npm --prefix frontend install
npm --prefix frontend run dev
```

Le serveur de développement tourne par défaut sur `http://localhost:5173` et transmet `/api` au backend sur `http://localhost:5000`.

Vérifications : `npm --prefix frontend run lint` et `npm --prefix frontend run build`.
